# 🕌 JinnahNew – University Website Frontend Practice Project

**JinnahNew** is a university-themed static website created as a frontend practice project using **HTML5, CSS3, and JavaScript**. It simulates a clean and responsive university landing page with sections like About, Courses, Contact, and more — perfect for showcasing web design fundamentals.

---

## 🛠️ Installation & Setup Guide

### 1. Clone the Repository

```bash
git clone https://github.com/SaharFatimaDevjani/JinnahNew.git
cd JinnahNew
```

### 2. Open the Project

Open the `index.html` file directly in your browser to view the project.

---

## 🚀 Key Features

- Sticky navbar with smooth scrolling  
- Interactive buttons and hover effects  
- Structured HTML5 and modular CSS  
- JavaScript used for UI interactivity
